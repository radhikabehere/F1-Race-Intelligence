📌 Project Overview
The *Formula 1 Race Intelligence Platform* is a data analytics web application built to analyze multi-season F1 race metrics, driver standings, lap sector telemetry curves, and team pit stop performance.

---

🛠️ Architecture & Data Schema
*5-Table Relational Model:* Synchronized key relationships between Drivers, Results, Circuits, Qualifying, and Telemetry datasets.
*Container-First Grid Layout:* Modern dark-mode electric blue aesthetic using glassmorphism styling.
*Tableau Embedding API (v3):* Clean web embedding using native custom elements (`<tableau-viz>`).
*GitHub Pages:* Automated deployment pipeline for global accessibility.
